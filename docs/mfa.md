# DevLink Multi-Factor Authentication (MFA / 2FA) Documentation (#639)

DevLink provides Time-based One-Time Password (TOTP) Multi-Factor Authentication (MFA) compatible with authenticator applications such as Google Authenticator, Authy, 1Password, Bitwarden, and Apple Passwords.

---

## 1. Overview & Security Architecture

- **TOTP Standard**: Standard RFC 6238 HMAC-SHA1 algorithm with a 30-second time step window.
- **Recovery / Backup Codes**: Generates 10 single-use 8-character hex recovery codes upon MFA setup.
- **Secure Hashing**: Recovery codes are hashed using SHA-256 before database storage.
- **Modular Design**: Architecture decoupled to easily accommodate future WebAuthn/FIDO2 passkey providers.

---

## 2. User Setup Flow

1. **Initialize Setup**: Navigate to `Settings -> Security` and click **Set Up Two-Factor Authentication**.
2. **Scan / Enter Secret**: Scan the QR code or copy the 32-character Base32 secret key into an authenticator app.
3. **Verify Code**: Enter the 6-digit TOTP code generated by your app.
4. **Save Recovery Codes**: Copy or download the 10 single-use recovery codes and store them in a secure password manager.

---

## 3. Login Verification Flow

1. User enters Primary Credentials (email + password).
2. If MFA is disabled, system returns access & refresh tokens immediately.
3. If MFA is enabled, system returns `mfa_required: true` and a short-lived `mfa_token`.
4. User enters 6-digit TOTP code or single-use recovery code.
5. System verifies code via `POST /api/v1/auth/mfa/verify-login` and issues full JWT session tokens.

---

## 4. REST API Endpoints

| Method | Endpoint | Description | Auth Required |
|--------|----------|-------------|---------------|
| `GET`  | `/api/v1/auth/mfa/status` | Retrieves current MFA status (`mfa_enabled`). | Bearer Token |
| `POST` | `/api/v1/auth/mfa/setup` | Generates TOTP Base32 secret and `otpauth://` provisioning URI. | Bearer Token |
| `POST` | `/api/v1/auth/mfa/enable` | Verifies initial TOTP code, enables MFA, and returns 10 backup codes. | Bearer Token |
| `POST` | `/api/v1/auth/mfa/disable` | Verifies TOTP or recovery code and disables MFA. | Bearer Token |
| `POST` | `/api/v1/auth/mfa/recovery-codes` | Regenerates 10 new recovery codes. | Bearer Token |
| `POST` | `/api/v1/auth/mfa/verify-login` | Completes 2FA login with `mfa_token` + `code`. | MFA Pending Token |
